# USDA REAP pre-application checklist

## Status

This is an initial internal preparation checklist. It is editable, versioned, and must be re-verified against current USDA Rural Development guidance before any submission.

The seeded categories are applicant, registration, site, utility, engineering, environmental, financial, commercial, legal, narrative, submission, post-award, and reimbursement.

## Known Project 001 status

- Complete internally: USDA REAP geographic eligibility evidence.
- Waiting: PSO circuit-capacity response.
- In progress: preliminary layout.
- In progress: production estimate.
- In progress: itemized construction quote.
- In progress: commercial off-taker strategy.
- Future: formal financing and grant deployment phases.

The seed does not mark applicant eligibility, application submission, award, environmental completion, matching funds, grant percentage, or grant amount.

## Verification policy

For any item treated as a current program rule, record:

- Source URL
- Source title
- Verification date
- Verified by
- Notes explaining interpretation or remaining uncertainty

Use `Needs USDA confirmation` when applicability is unclear. Use `Not applicable` only after the project team records a basis for the decision.
